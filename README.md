# React + TypeScript + Vite

## Задание по оптимизации

Реализовала несколько подходов для оптимизации веб-приложения:

- сделала динамический импорт React-компонентов через React.lazy и обернула в Suspense для отображения fallback UI во время загрузки;
- внедрила компонент ErrorBoundary для отлова и корректной обработки ошибок, возникающих при загрузке или рендеринге компонентов;
- реализовала механизм бесконечной подгрузки данных с API по 20 элементов на страницу, с загрузкой новых данных при прокрутке вниз.
